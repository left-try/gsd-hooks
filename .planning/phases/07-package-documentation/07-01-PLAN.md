  <files>README.md</files>
  <action>
    Append to README.md:

    1. **How it works** — three subsections:
       - **Economy mode**: `npx gsd-economy --on` / `--off` (or `gsd-economy` if on PATH via package bin).        - **Phase pacing** (Claude Code only): Stop hook delays between phases; default 15s via `GSD_PHASE_DELAY_SECS`; per-project override via `hooks.phase_delay_secs` in `.planning/config.json` (when key present, overrides env entirely; `0` disables); skipped when `.planning/economy.lock` exists (429 cooldown supersedes).

    2. **Configuration reference** — table or definition list:

       - `gsd-economy --on` / `gsd-economy --off` — manual economy toggle
       - `GSD_BACKOFF_TEST_MS` env var — optional test override for cooldown duration (mention briefly for developers only)
