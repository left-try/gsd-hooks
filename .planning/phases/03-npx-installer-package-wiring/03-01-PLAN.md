<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installer → ~/.claude/settings.json | Installer modifies a global user config file |
| installer → ~/.claude/plugins/ | Installer writes new files into the user's Claude plugin directory |
| npx cache → local execution | Package executes from npx cache; no global install |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | ~/.claude/settings.json | mitigate | Write settings-hooks-restore.json snapshot of original hooks block before any modification; install is reversible |
| T-03-02 | Denial of Service | install.js | mitigate | Wrap main logic in try/catch; exit 1 with message on any fs error to prevent silent partial install |
| T-03-03 | Tampering | Hook command paths | mitigate | Resolve hook paths from __dirname (package-relative), not user-supplied input; no argv interpolation into command strings |
| T-03-04 | Information Disclosure | printSummary output | accept | Summary only reveals file paths in user's own home directory; no secrets logged |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No third-party packages installed; only Node.js built-ins (fs, path, os) used — no supply chain exposure |
</threat_model>
