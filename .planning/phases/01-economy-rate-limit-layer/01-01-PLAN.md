Create `hooks/gsd-economy.js` as a Node.js CommonJS script with shebang `#!/usr/bin/env node`.

Structure:

1. Resolve four paths using `path.join(process.cwd(), '.planning', ...)`:
   - `configPath` → `.planning/config.json`
   - `lockPath` → `.planning/economy.lock`
   - `restorePath` → `.planning/economy-restore.json`
   - `presetPath` → resolved from `__dirname/../presets/economy.json`

2. Helper `readJsonOrEmpty(filePath)`: returns parsed JSON if file exists, else `{}`.

3. Helper `deepMerge(target, source)`: recursively merges source into target, returning a new object. Used to apply the economy diff and to restore keys.

4. `activate()` function (implements ECON-01, ECON-03, ECON-04):
   - If `lockPath` exists: print "Economy mode already active" and exit 0
   - Read current config with `readJsonOrEmpty(configPath)` — save as `original`
   - Load economy diff from `presetPath`
   - Build restore snapshot: extract from `original` only the keys present in the diff (at all nested levels). Save as `.planning/economy-restore.json` via `fs.writeFileSync` (create `.planning/` dir if needed via `fs.mkdirSync(..., { recursive: true })`)
   - Write patched config: `deepMerge(original, diff)` → `fs.writeFileSync(configPath, JSON.stringify(merged, null, 2))`
   - Write lock file: `fs.writeFileSync(lockPath, new Date().toISOString())`
   - Print "Economy mode activated"

5. `deactivate()` function (implements ECON-02, ECON-04):
   - If `lockPath` does not exist: print "Economy mode not active" and exit 0
   - If `restorePath` does not exist: print error and exit 1
   - Read current config with `readJsonOrEmpty(configPath)`
   - Read restore snapshot from `restorePath`
   - Merge restore snapshot back: `deepMerge(current, restore)` → write to `configPath`
   - Delete lock: `fs.unlinkSync(lockPath)`
   - Delete restore: `fs.unlinkSync(restorePath)`
   - Print "Economy mode deactivated — config restored"

6. Parse `process.argv[2]`: `--on` → `activate()`, `--off` → `deactivate()`, else print usage and exit 1.

Do NOT use any npm packages. Use only `fs`, `path` from Node.js builtins. Mark the file executable-compatible with the shebang but do not rely on Unix chmod — the npx installer (Phase 3) handles that.

| T-01-03 | Information Disclosure | economy-restore.json | accept | File contains only config values the user already controls; no secrets |
