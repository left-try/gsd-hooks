Create `hooks/gsd-429-guard.js` as a Node.js CommonJS script with shebang `#!/usr/bin/env node`.

Structure:

1. Resolve paths:
   - `transcriptPath` = `process.env.CLAUDE_TRANSCRIPT_PATH`
   - `logPath` = `path.join(process.cwd(), '.planning', 'rate-limit-log.json')`
   - Import `activate` from `./gsd-economy.js`: `const { activate } = require('./gsd-economy');`
     NOTE: gsd-economy.js must export `activate` — the executor must verify this export exists after Plan 01 lands. If gsd-economy.js currently runs as a CLI top-level script, refactor it to export `activate` and `deactivate` before the `process.argv` block so this require works.

2. `RATE_LIMIT_SIGNALS` constant: `['429', 'rate_limit_error', 'Too Many Requests', 'rate limit']`

3. `detectRateLimit(filePath)`: reads file as UTF-8 string, returns `true` if any signal string appears in content, else `false`. Returns `false` if file cannot be read (ENOENT or other error caught).

4. `appendLog(logPath, entry)`: reads existing array from `logPath` (or `[]` if absent/unreadable), pushes `entry`, writes back as pretty-printed JSON. Creates `.planning/` dir with `{ recursive: true }` if needed.

5. `sleep(ms)`: returns `Promise` resolved after `ms` milliseconds via `setTimeout`.

6. Main async IIFE:
   ```
   (async () => {
     if (!transcriptPath) process.exit(0);
     if (!detectRateLimit(transcriptPath)) process.exit(0);
     // 429 detected
     activate();  // idempotent — safe to call even if already active
     appendLog(logPath, { timestamp: new Date().toISOString(), event: '429_detected', source: transcriptPath });
     console.log('[gsd-429-guard] Rate limit detected — economy mode activated, cooling down 60s');
     await sleep(60_000);
     process.exit(0);
   })();
   ```

Do NOT use any npm packages. Use only `fs`, `path`, Node.js builtins. The `activate` import requires gsd-economy.js to export the function — add `module.exports = { activate, deactivate }` at the bottom of gsd-economy.js (after the argv dispatch block) so it works both as a CLI and as a require'd module.

| T-02-03 | Denial of Service | 60s sleep in Stop hook | accept | Intentional — the cooldown IS the feature; Claude Code chains will wait |
