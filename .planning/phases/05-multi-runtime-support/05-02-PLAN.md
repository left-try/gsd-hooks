    hooks/gsd-gemini-before.js (BeforeAgent):

    1. Read all stdin into buffer; parse with readStdinJson from hooks/lib/runtime-hook.js.

    2. Resolve cwd = typeof input.cwd === 'string' ? path.resolve(input.cwd) : process.cwd().

    3. If path.join(cwd, '.planning', 'economy.lock') exists: call activate({ cwd }) from gsd-economy.js (idempotent when already active).

    4. emitJsonStdout({ suppressOutput: true }) — Gemini requires JSON-only stdout.

    5. Log informational messages to stderr only (prefix [gsd-gemini-before]).

  hooks/gsd-gemini-after.js (AfterAgent):

    1. Read stdin JSON same as above; resolve cwd.

    2. transcriptPath = input.transcript_path (string) or ''.

    3. sessionKey = resolveSessionKeyFromInput(input, transcriptPath).

    4. If transcriptPath: await runGuard({ transcriptPath, cwd, sessionKey }) from gsd-429-guard.js.

    5. emitJsonStdout({ suppressOutput: true }) after guard completes (hook blocks during cooldown — intentional, matches Claude SubagentStop semantics).

    6. stderr for [gsd-gemini-after] logs only.

    Do NOT use exit code 2 for 429 recovery — economy activation is advisory; retry is handled by Gemini runtime separately. Do NOT print plain text to stdout.
  </action>
